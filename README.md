# This Horrible Textbook

This textbook, CompTIA A+ Guide to Information Technology Technical Support (11th edition), is absolute trash. It's absurd that this is allowed to be used in college courses, and even if ignoring everything else Cengage does, they are a terrible company for letting this textbook be released.

I would like to emphasize that it costs $50 to rent this textbook digitally, $114 including the homework, and ~$100-200 to buy it, depending on whether you want a loose-leaf, paperback, or hardback copy. Anything more than $0 for this quality is a scam.
